六场景任务库：拿来就用的任务模板 ​

六场景任务库收录六大高频场景的即用指令模板。每个场景：场景说明 → 标准指令 → 变体指令 → 常见坑。复制指令、替换内容，立刻能用。

使用说明

  • 标准指令：通用版本，直接套用；
  • 变体指令：场景变化时微调；
  • 配套章节：想深入原理，看对应章节。

场景一：写作与文档 ​

适用：报告、方案、文案、总结、白皮书等一切写作任务。

text
请帮我写一份【文档类型】：
- 目标：【要达成的效果】
- 读者：【给谁看，他们关心什么】
- 输入：【参考资料路径/内容】
- 结构：【章节要求】
- 风格：【语气/长度/格式】
- 验收：【怎么算写好了】
  • 变体：改"目标"为"给领导汇报用，结论先行，不超过 3 页"；
  • 常见坑：不给定结构 → 先出大纲确认再动笔；
  • 配套章节：第 2、9 章。

场景二：数据处理与分析 ​

适用：清洗、汇总、统计、对比、找异常等数据任务。

text
分析【文件路径】：
1. 先看数据结构（字段/缺失/样例）
2. 确认口径：【统计规则，如"不含税、按支付时间"】
3. 按【维度】汇总，输出到【输出路径】
4. 标出异常（环比/同比变化超阈值）
5. 附口径说明，我能复核
  • 变体：加"生成图表"或"输出对比表"；
  • 常见坑：口径不确认就开算 → 先对齐口径；
  • 配套章节：第 12 章。

场景三：代码开发与调试 ​

适用：写脚本、改 bug、加功能、重构。

text
【描述任务】。要求：
1. 先读相关代码，理解上下文再动手
2. 最小改动，展示 diff 给我确认
3. 完成后运行【测试/验证命令】证明可用
4. 不可逆操作（删除/覆盖/推送）先问我
  • 变体：加"输出为 Skill"或"附注释和日志"；
  • 常见坑：不让它验证就交付 → 必须"跑通再交付"；
  • 配套章节：第 3、10 章。

场景四：信息收集与调研 ​

适用：行业动态、竞品分析、资料整理。

text
调研【主题】：
1. 信息来源：【链接/文件/你提供的资料】
2. 筛选标准：【相关度/时效/可信度】
3. 输出：按【分类】汇总，每条含"一句话要点 + 来源 + 影响判断"
4. 拿不到原文的标"待核实"，不编造
  • 变体：改为"每日简报"或"对比报告"格式；
  • 常见坑：让它联网编信息 → 明确"只基于我给的资料"；
  • 配套章节：第 14 章。

场景五：文件与目录管理 ​

适用：整理、归档、批量重命名、搜索定位。

text
整理【目录】：
1. 先盘点（文件数/类型分布），给出整理计划
2. 计划含"每个文件去哪"，我确认后执行
3. 批量操作先备份或干跑
4. 输出变更日志，可回退
  • 变体：加"按日期归档"或"统一命名规则"；
  • 常见坑：不备份直接批量改 → 先备份再动手；
  • 配套章节：第 11 章。

场景六：会议与协作 ​

适用：会议纪要、需求提炼、任务分派、团队协作。

text
处理【会议记录/聊天记录】：
1. 提炼：决策 / 行动项（谁做什么、何时完成）/ 待确认问题
2. 输出格式：【纪要模板】
3. 行动项明确负责人和截止时间
4. 有歧义的内容单独标注
  • 变体：改为"生成周报素材"或"需求清单"；
  • 常见坑：只总结不复盘 → 要求"行动项 + 负责人"；
  • 配套章节：第 13、16 章。

通用四要素模板（万能兜底） ​

记不住具体模板时，用这个万能版：

text
任务：{做什么}
目标：{要达成的效果}
输入：{资料在哪}
约束：{格式/长度/语言/风格}
验收：{怎么算完成}

把这五句话填满，任何任务都能开跑。
