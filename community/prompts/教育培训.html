🎓 教育培训 · 5 条提示词模板 ​

这行的活有两头：一头是教学（备课、批改、上课），一头是招生与家长（介绍、沟通、续费）。 很多人教学很行，但两头的时间被撕碎了。

本行三句话骨架 ​

text
我带的是【什么学段 / 什么科目 / 什么班型 / 学员什么基础】。
帮我产出【教案 / 反馈 / 沟通话术】，篇幅【…】。
按【考纲 / 我的教学风格 / 你们机构的规矩】来；具体到人的信息用我给的，别编。

1 · 课程介绍 → 让家长看懂"我孩子能得到什么" ​

什么时候用：写招生简章、朋友圈介绍、课程顾问话术，总在写"名师执教、小班教学"这种谁都会写的话。

text
我的课程：【科目 / 学段 / 班型人数 / 总课时 / 价格】
学员现状：【典型学员是什么水平，有什么典型问题】
我真正比别人强在哪：【1-2 条，必须是真的，例如"每次课都留 15 分钟一对一答疑"】
家长最担心什么：【…】

帮我写三份不同长度的介绍：
① 50 字版（发朋友圈 / 群）
② 200 字版（公众号 / 介绍页）
③ 一段 30 秒的口头介绍（顾问照着念）
每份都要：先写"孩子的具体处境"，再写"我们怎么解决"，最后写"能看见的结果形式（不是分数承诺）"。
规矩：不许出现"提分快""保过""名师"这类词，除非我有真实可查的依据；不许承诺分数。

它给你：三份长度的介绍。"先说孩子的处境"是转化的关键，比堆优势有用。

2 · 一节课的教案（含时间轴和提问设计） ​

什么时候用：你要上的一节课，内容你熟，但"怎么讲得不困、怎么知道他们懂了"要花时间设计。

text
这节课：【科目 / 学段 / 课题 / 时长（例如 45 分钟）】
学员水平：【…】，班上大概【…】人
这节课的目标：【学生下课后必须会做什么（可检验的）】
我手里有的材料：【教材 / 例题 / 习题，粘贴关键内容】

帮我设计教案，必须包含：
① 时间轴（分钟级切分，含"开场 3 分钟怎么抓注意力"）
② 每段的"老师做什么 / 学生做什么"两列
③ 至少 4 个提问，并标明每个问题是"查记忆"还是"逼思考"
④ 一个"全班都会但其实是假懂"的检查点（容易混淆的地方）
⑤ 最后 3 分钟的收尾与作业布置
规矩：不要用我材料里没有的知识点；不确定学段难度是否合适的地方标出来。

它给你：一份带时间轴的教案。第④条"假懂检查点"最值钱。

3 · 作业批改：批量评语 + 个性化反馈 ​

什么时候用：一堆作业要批，你想给每个人写一句有用的话，但时间不够。

text
这是我这次作业的情况：
① 普遍性的问题：【…（照实写）】
② 下面 5 个学生的具体情况（我用代号代替姓名）：
学生 A：【错在哪 / 漏了什么 / 值得表扬的一点】
学生 B：【…】
（依次）

帮我：
① 写一段"全班共性问题"的讲评（不超过 150 字，先讲清楚错在哪，再讲怎么做对）
② 给每个学生写 2 句话反馈：第一句具体说他的问题或进步，第二句给一个可执行的小动作
规矩：不评价孩子的性格和能力（不说"粗心""聪明""态度不好"），只说行为；不要用空洞的"加油"占位置。

它给你：一段讲评 + 每人两句。"只说行为不评价人"这条务必保留——写对了，家长会感谢你。

4 · 家长沟通：进步怎么说、问题怎么说、续费怎么开口 ​

什么时候用：要给家长发消息，尤其是"报忧"和"谈续费"，措辞很费心。

text
家长情况：【孩子年级 / 家长的性格和关注点 / 之前沟通过什么】
我要说的事：【孩子最近的真实表现，好的和不好的都写】
我的目的：【单纯反馈 / 提醒注意 / 谈续费 / 处理不满】

帮我写一条微信消息，三段式：
① 先给一个具体的事实（细节，不是评价）
② 再说问题或建议（给一个家长今晚在家就能做的小动作）
③ 最后给一个明确的下一步（我下节课会怎么做 / 什么时候再反馈）
长度：150 字以内，适合微信直接发，不要太"官方"。
如果是要谈续费，另外给我一个"不提钱的钩子版本"。
规矩：不许编孩子的表现，只写我给的；不能承诺保证效果。

它给你：一条可直接发的消息（约 150 字）。"一个家长今晚就能做的小动作"是这行的口碑来源。

5 · 阶段学习报告（给家长看的那一页纸） ​

什么时候用：期中、期末、结课，要出一份报告，比"分数+评语"更有说服力。

text
学员：【代号 + 学段 / 科目 / 学了多久 / 课时数】
开始的水平：【…（用具体表现描述，例如"有理数计算经常出错"）】
现在的水平：【…】
过程中的记录：【哪几次课有明显变化 / 什么题类型突破了 / 什么还没解决】

帮我生成一份一页纸学习报告：
① 起点：进来时是什么状态（用具体表现，不用分数）
② 变化：中间发生了什么（3 个节点，带时间和具体事例）
③ 现在：能做什么、还不能做什么（各写 2 条，诚实）
④ 下一步建议：下阶段 3 个重点 + 家里可以配合的 1 件事
⑤ 一段不超过 80 字的"我看到的这个孩子"（写行为与特点，不写评价套话）
规矩：所有内容必须来自我给的记录，不许补；没有的节点就不写。

它给你：一份能让家长觉得"老师真的在看我孩子"的报告。

⚠️ 这行的三条红线 ​

  1. 不许承诺分数、名次、录取。这是这行最容易踩的雷，也是 AI 最爱帮你说的话。
  2. 不要给"诊断式"标签：多动、注意力缺陷、学习障碍这类词，轮不到我们下判断。发现异常，建议家长找专业机构。
  3. 未成年人信息要保护：姓名、照片、成绩、家庭情况，给 AI 处理前一律用代号，别把原表直接粘进去。
